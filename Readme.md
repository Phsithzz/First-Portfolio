# Personal Portfolio - Phoosith Pheanchob

เว็บไซต์พอร์ตโฟลิโอส่วนตัวของ **นายภูสิทธิ เพียรชอบ** นักศึกษาคณะวิทยาศาสตร์ สาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตศรีราชา

## 🔎 รายละเอียดโปรเจกต์

เว็บไซต์นี้เป็นหน้าเว็บแบบ Static HTML/CSS สำหรับแสดงข้อมูลส่วนตัว ประวัติการศึกษา เป้าหมายในอนาคต และช่องทางติดต่อ

### 📌 Sections ที่อยู่ในเว็บไซต์

- **Home** – แสดงชื่อ นิสิตรหัส และข้อมูลเบื้องต้น
- **Education** – ประวัติการศึกษาจากระดับประถมถึงมหาวิทยาลัย
- **Future Goals** – แผนและเป้าหมายในอนาคตของผู้จัดทำ
- **Contact Me** – ช่องทางการติดต่อผ่าน Facebook และ Instagram

## 🧰 Technologies Used

- HTML5
- CSS3 (ใช้ custom styling + responsive layout)
- Font Awesome (icons)
- Google Fonts 


## ✅ วิธีใช้งาน

1. ดาวน์โหลดหรือ clone repo นี้
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์
3. ตรวจสอบว่าไฟล์ `style.css` และรูปภาพอยู่ในตำแหน่งที่ถูกต้อง
